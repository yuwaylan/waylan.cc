# 個人網站內容與展示計劃

本次依使用者核可的計劃調整，包含 2026-09-10 補充的半導體系統資料，以及 Be水水網頁版、狀態頁和動態效果需求。

## 首頁順序

1. 自我介紹：姓名、照片、目前工作與研究背景。
2. 工作經歷：必水水、島宇、萬能科技大學。來上客、族語 E 樂園、哈客網路學院僅提供官方連結；哈客工作範圍為系統維運。
3. Be水水：App 與網頁服務。首頁展示附近工作室、技師行事曆，詳頁再展示服務選擇與顧客標籤。提供網頁版及服務狀態連結。
4. 研究與發表：YOLOv8 皮膚紋理研究與四階段比較、OCR 研討會發表資料。
5. 其他開發專案：人格特質 App、半導體報名系統、NLP 聊天機器人。
6. 早期作品：首頁精選四件，完整索引保留九件與本人分工。
7. 學歷、證照、教學與獎項。

- 半導體布局設計工程師能力鑑定報名系統：使用者確認於 **2020 年維運**，使用 **Django + MySQL**。保留當年名稱，僅連到 https://icdesign.tw/ ，不使用現行網站截圖，不將現行名稱或介面視為當年的成果。
- Be水水有 App 與網頁；網頁入口 https://besuisui.com/ ，服務狀態 https://status.besuisui.com/ 。不自行推定即時服務狀態。
- 人格特質分析：國科會計畫 **MOST109-2410-H155-026**，以研究用 App 與後端開發為主；商店畫面僅作歷史資料。
- OCR：余程漢、方文聘，〈以視覺辨識方法設計輔助文字資料搜尋之行動裝置程式〉，2023 離島研討會（ITAOI2023），宜蘭大學。

## 素材處理

所有新公開圖均為使用者提供的圖片，做確定性的裁切與 WebP 壓縮，未生成或重畫 App 介面、研究輸出。

- `be-nearby.webp`、`be-calendar.webp`：移除頂端系統狀態列，保留 App 導航與功能畫面。
- `be-booking.webp`：取服務選單局部，保留價格、時長與選擇狀態。
- `be-customer-tags.webp`：只保留顧客標籤；姓名、電話、頭像、個人備註與消費紀錄未輸出至公開檔案。
- `personality-app.webp`、`personality-profile.webp`：取自歷史上架截圖中的兩個 App 畫面；未輸出含聯絡資訊的研究告知畫面，也未輸出商店安裝按鈕。
- `skin-original.webp`、`skin-prediction.webp`、`skin-contour.webp`、`skin-overlay.webp`：從論文圖 4-12 裁出四個既有圖版；`skin-results.webp` 保留完整原圖及圖說。
- `skin-data.webp`、`skin-model.webp`：保留研究原圖標示與浮水印。
- 三個語言平台與半導體網站皆不使用截圖。

原始履歷、未處理的顧客詳情圖與聯絡資訊不得放入 `public/`。

## 互動與可用性

- 動畫預設啟用，移除頁面動態開關與舊的動態偏好讀取。
- 尊重 `prefers-reduced-motion`；保留靜態可讀內容。
- Anime.js 驅動產品雙畫面的不同步視差、照片與早期作品視差、章節和工作經歷進度線、架構連線、研究切換及圖片視窗動畫。
- 手機使用原生橫向捲動、scroll snap 與文字按鈕切換，不自動輪播。
- 圖片視窗可查看原始尺寸、切換圖片、Escape 關閉並將焦點送回原連結。
- 未啟用 JavaScript 時，圖片、研究四圖、內文與原始圖片連結仍可閱讀。
